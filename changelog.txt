## 0.2.0 - 2026/09/07

这版把战斗底子搭起来了：三系伤害、三系抗性、混乱值，还有侵蚀 EGO 的全屏着色器效果。
另外玩家数据和界面也顺手整理了一遍。

- 新增 混乱值（Stagger）系统：满值起步，挨打就掉，掉到 0 直接混乱 15 秒
  - 混乱期间不能移动、不能攻击，也不能放 EGO，客户端整个锁死（连 ESC 都按不动）
  - 服务端每 tick 把玩家拉回原位，别想着靠卡输入跑掉
  - 怪物一样吃这套：清目标 + 停寻路 15 秒，进混乱时冒一圈粒子，玩家看得见
  - 不受击时每 2 秒回 1 点，不至于被摸两下就打崩
  - 挨打窗口：混乱期间受到的伤害 ×1.5
  - 三段接口留好了（进入前 / 混乱中每秒 / 结束），战斗和表现效果以后接这里
- 新增 三系伤害类型：斩击 / 突刺 / 打击
  - 判定走三层：代码注册 → 数据包 tag → 兜底推断，mod 和整合包都能接
  - 剑斧类算斩击，三叉戟 / 锄 / 弓弩算突刺，镐锹算打击，空手算打击
  - 弹射物一律当突刺，爆炸当打击，实在判不出来的一律打击（不会因为判错把伤害吞掉）
- 新增 三系抗性：致命 ×2 / 弱点 ×1.5 / 普通 ×1 / 耐性 ×0.5 / 免疫 ×0
  - 怪物抗性用数据包 tag 配：#limbusexplore:resist/slash/fatal 这一类，加个 json 就行
  - 抗性同时管 HP 伤害和混乱伤害，两边的数值不会打架
  - 数值语义跟图书馆、巴士一致，改分级直接动 Resistance 里的常量
- 新增 伤害公式骨架：伤害 = 原伤害 × 抗性 × 等级差修正
  - 等级差这项现在恒等于 1.0，等等级系统做完再开（每级 3%，巴士的算法）
  - 我们是乘算，不改别的 mod 已经算好的伤害，冲突面小
- 新增 侵蚀 EGO 的全屏效果：Voronoi（Worley）细胞 + 三维柏林噪声
  - 三个维度分别喂 R / G / B，EGO 类型决定三维权重（暴怒偏红、忧郁偏紫这种）
  - 一瞬间会爆闪 + 一圈脉冲环，30 秒状态期间细胞慢慢流动、边界呼吸
- 新增 调试命令：/chaos、/resistance（/sins、/sanity 早就有）
- 新增 配置项 damageKindEnabled，服主可以整体关掉本 mod 的伤害倍率
- 修复 侵蚀着色器贴图采样写法：GLSL 不允许 sampler 走三目运算，改成两张图都采样再选
- 修复 着色器资源路径：ShaderInstance 只认 minecraft 命名空间，文件挪到 assets/minecraft/shaders/core
- 修复 侵蚀一瞬间闪光的播放条件，不再依赖状态包的到达顺序
- 优化 三个玩家同步类（罪孽 / 理智 / EGO 状态）合并成一个 PlayerDataSync，事件监听集中一处
- 优化 释放界面渲染：纹理查询结果和已装备列表加缓存，不再每帧翻资源包
- 优化 EGO 释放链路：判定统一在服务端，客户端只做预检和展示

## 0.1.0 - 2026/09/06

第一版框架，先把都市探索要用的底子搭出来。

- 新增 工程骨架：Forge 1.20.1（47.3.0）+ Gradle 8.8 + Mojang 官方映射
- 新增 罪孽资源：七种罪孽挂在玩家身上，左侧 HUD 竖排显示，H 键开关
  - 数据存玩家身上（不是物品），死亡重生的数据跟着走
  - 配套 /sins 调试命令
- 新增 理智值（SP）：范围 -45 ~ 45，显示在快捷栏右侧
  - 0 以上用蓝色图标，0 以下换红色图标，数字画在图标中间
  - 掉到 -45 视为崩溃（判断接口留着，行为等战斗系统）
- 新增 EGO 系统
  - 五个槽位按等级绑定：1=ZAYIN、2=TETH、3=HE、4=WAW、5=ALEPH，装错等级装不进去
  - G 键打开装备界面（左键装备、右键卸下），R 键打开释放界面
  - 释放消耗罪孽资源组合 + 理智，服务端判定，客户端只做预检
  - 释放界面长按 500ms 切成侵蚀态（卡片变红、消耗 ×1.5、允许透支成负数），右键取消
  - 释放后进入 30 秒 EGO 状态，HUD 显示倒计时，期间不能再放
- 新增 侵蚀视觉雏形：侵蚀一瞬间和侵蚀横幅两张图，全屏铺开、淡入淡出
- 新增 /sanity 调试命令
